## 课程地图

自顶向下走完整个协议栈，每阶段都落在动手实验上：

| 阶段 | 课时 | 学完你能 |
|---|---|---|
| 1 · 学习诊断与环境准备 | 01 | 摸清自己的起点，装好 Wireshark / Packet Tracer / Python，立下实验安全红线 |
| 2 · 网络全景与工具入门 | 02–03 | 讲清"输入网址后发生了什么"，理解分层与封装，完成第一次抓包分析 |
| 3 · 应用层实战 | 04–07 | 抓包分析 HTTP/HTTPS/DNS/DHCP 流量，读懂请求响应与域名解析全过程 |
| 4 · 传输层与 Socket 编程 | 08–11 | 解释 TCP 三次握手、可靠传输与拥塞控制，用 Python 写出 Echo 与聊天室 |
| 5 · 网络层与路由 | 12–16 | 掌握 CIDR 子网划分与路由原理，在 Packet Tracer 搭出多路由器企业网 |
| 6 · 链路层与局域网 | 17–20 | 解读以太网帧与 ARP，配置 VLAN 与 Trunk，完成局域网综合抓包项目 |
| 7 · 无线网络与性能排障 | 21–23 | 理解 802.11 与 WPA 演进，按方法论定位真实网络故障 |
| 8 · 网络安全实战 | 24–27 | 拆解密码学与 TLS 握手，配置 iptables、执行授权扫描、画出安全架构 |
| 9 · 综合项目与考核 | 28–30 | 独立交付三域企业安全网络，限时定位注入的故障，完成口述答辩 |

每课以七节组织：编号小节讲透原理，固定以「实战任务」与「掌握验证标准」收尾；四个阶段项目（课时 11 Socket 聊天室 / 课时 16 企业网络仿真 / 课时 20 局域网综合抓包 / 课时 28 安全网络架构）贯穿始终。

## 课程特点

- **知识有出处**：主干蒸馏自 Kurose & Ross《自顶向下方法》，协议细节以 RFC 原文为准——每个技术点对应教材哪一章、哪份标准，一课一行列在[知识溯源清单](docs/sources.md)里；
- **编排成线**：自顶向下走完协议栈，每课从一个真实问题开始（"浏览器输入网址后发生了什么？"），四个阶段项目把知识串成可展示的作品；
- **讲人话**：先类比后术语——封装是"俄罗斯套娃快递"，DNS 是"查通讯录"，加密是"明信片 vs 密封信"；术语首次出现给中英对照，不假设你读过教材；
- **电子书的体验**：学习状态存在浏览器本地，关掉再开进度还在；代码块一键复制、默认折叠不占屏；
- **单文件即全书**：一个 HTML 文件装下 30 课时的全部内容，离线可读，协议图表全由 CSS 绘制，放大不糊。

## 知识溯源

课程知识不是凭空生成的，而是蒸馏自一个有据可查的知识库：主干是 Kurose & Ross《计算机网络：自顶向下方法》第 8 版，协议细节以 16 份 RFC 与 IEEE 标准原文为准，实验取自 Kurose 官方 Wireshark Labs 的脱敏 trace 与 Cisco Packet Tracer。哪个知识点来自哪里，一课一行，详见 **[📚 知识溯源清单](docs/sources.md)**。
